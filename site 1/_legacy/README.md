# STROKES Website - NIT Durgapur

Welcome to the official website repository for **STROKES**, the Art and Photography club of NIT Durgapur. This website showcases the creative works of our members, including photography exhibitions and artwork galleries.

## 🌟 Features

*   **Multi-Page Layout**:
    *   **Home**: Introduction to the club with a hero section.
    *   **Exhibition**: A photo gallery showcasing photography skills.
    *   **Art Work**: A gallery dedicated to sketches, paintings, and digital art.
    *   **About Us**: Information about the club's mission and team.
*   **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.
*   **Modern Aesthetics**: Styled with a premium Deep Navy & Gold color palette.
*   **Animations**: Smooth fade-in scroll animations and hover effects on gallery items.
*   **Vanilla Tech Stack**: Built with pure HTML, CSS, and JavaScript for maximum performance and zero dependencies.

## 🚀 How to Run

Since this is a static website, you don't need to install any complex dependencies or servers.

### Method 1: Open Directly
1.  Download or clone this repository.
2.  Navigate to the project folder.
3.  Double-click on `index.html` to open it in your default web browser.

### Method 2: Live Server (VS Code)
If you are using Visual Studio Code:
1.  Install the "Live Server" extension.
2.  Right-click on `index.html`.
3.  Select "Open with Live Server".

## 🛠️ Technologies Used

*   **HTML5**
*   **CSS3** (Flexbox, Grid, CSS Variables)
*   **JavaScript** (ES6+)
